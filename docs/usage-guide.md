# Echo 使用与操作指南（含手势坐标）

> **面向谁**：第一次接触 Echo 的使用者或测试 agent。读完本文应能不看源码
> 完成全部现有交互、找到每个可点区域、判断反馈是否符合预期。
>
> **坐标系约定**：本文坐标均为 Flutter 逻辑像素（不是物理像素），原点在
> **屏幕左上角**，x 向右、y 向下；`w` = 屏宽、`h` = 屏高、`sb` = 底部安全区
> （手势条高度）。第 5 节给出公式与参考机（w=360）数值，所有坐标都能按
> 屏宽换算。**几何唯一事实来源是
> [`DockGeometry`](../echo/lib/src/navigation/dock_geometry.dart)，本文数值
> 与代码不一致时以代码为准并修本文。**

## 1. 这是什么软件

Echo 是一个实验型底部手势导航 App。屏幕上**没有常规底部 Tab 栏和顶部
标题栏按钮**，全部操作集中在屏幕底部同一水平线上的「三条」：

```
 ┌────────────────────────────────────────────┐
 │                                            │
 │              页 面 内 容 区                 │
 │        （终端 / 聊天 / 日志 / 我）           │
 │                                            │
 │                                            │
 │  ▌        ▌▌▌▌▌▌▌            ●▔▔▔▔●        │
 │ 把手      AI 条                    导航条    │  ← 距底部 16+sb
 │ 12vw      38vw−56                  半屏宽    │
 └────────────────────────────────────────────┘
   x=14      x=71.2~152          x=166~346(w=360)
```

- **把手条**（左下）：点按弹「本页操作竖单」、右拖出侧边抽屉
- **AI 条**（中间虹彩条）：**只有长按**有用，单击无任何反应（不是坏了）
- **导航条整体**（右下，含两端小圆点）：翻页、上甩快捷弧、双击直达、长按搜索

三条等高 **10px**、距底部 **16+sb**、与屏幕边缘及彼此间距统一 **14px**。
视觉上只有 10px 高，但三条都有**隐形纵向热区**（向上扩 32、向下扩 10），
实际可按高度为 52px，并不难按。

## 2. 页面结构

横向共 4 页，顺序固定（配置在
[`nav_destination.dart`](../echo/lib/src/navigation/nav_destination.dart)）：

| 序号 | 页名 | 现状 |
|---|---|---|
| 0 | **终端** | 模板页 + debug 调试按钮（仅 debug 包；英文 kicker 仍为 CONSOLE） |
| 1 | **聊天** | 真实页面：会话列表（左滑操作、未读绿点） |
| 2 | **日志** | 模板页 + debug「处理异常」按钮（仅 debug 包） |
| 3 | **我** | 纯模板页 |

在页面之间移动只能靠导航条族手势（横滑 / 圆点 / 双击 / 搜索结果跳转）。

## 3. 操作速查表

| # | 操作 | 按在哪里 | 触发条件 | 反馈 | 如何取消/反悔 |
|---|---|---|---|---|---|
| 1 | **点圆点翻页** | 导航条两端圆点热区 | **按下即触发**，不等松手 | 振动 tick、翻一页、圆点 tone1→tone2 持续 200ms | 已翻页，无反悔 |
| 2 | **横滑翻页** | 导航条本体热区 | 横移 >8px 且 >1.11×纵移即锁定 | 右下 3D 数字转鼓与左下衬线页名牌浮现（同升同收）、滑块跟手；松手就近吸附或惯性翻多页 | 未锁向时松手=单击；锁定后必翻页 |
| 3 | **双击直达** | 导航条本体 | 300ms 内第二下 | 直接跳到第二下 x 对应的页 | — |
| 4 | **上甩快捷弧** | 导航条本体 | 上移 >16px 且 >2×横移 | 快捷弧从底部沿弧弹出，最近按钮高亮、tick | 手指移出全部热区再松手=不触发 |
| 5 | **长按搜索** | 导航条本体 | 按住 **450ms** 不移动 | confirm 振动、搜索框展开 | 450ms 内移动即转横滑/上甩 |
| 6 | **点按把手** | 把手条热区 | 点按（未发生横/纵移动） | confirm 振动、竖单向上生长 | 点遮罩 / 返回键只收起 |
| 7 | **右拖抽屉** | 把手条热区 | 横移 >6px 且占优 | 抽屉跟手、把手移向停靠位 | 拖回 <半程 松手=关闭 |
| 8 | **长按 AI 条** | AI 条热区 | 按住 **450ms**，移动 ≤8px | confirm 振动、对话框升起并弹键盘 | 移动 >8px 取消；单击故意无动作 |
| 9 | **聊天行左滑** | 聊天页会话行 | 向左拖 | 露出两个操作按钮 | 半程内松手 / 竖滚列表收回 |
| 10 | **返回键** | 系统返回 | 有浮层时 | 逐层关浮层（见第 8 节顺序） | 无浮层才退出 App |

## 4. 各组件操作详解

### 4.1 翻页圆点（左右各一个，直径 10）

- **位置**：右圆点右边贴 `w−14`；左圆点在导航整体（宽 w/2）的左端；
  圆点与导航条本体之间隔 5px（一个半径）。
- **热区**：以圆点为中心、**宽 20px**（直径 2 倍）、纵向
  `条顶−32 ~ 条底+10`（52px 高）。圆点热区与导航条热区只相接不重叠，
  按交界处不会歧义。
- **左圆点 = 上一页**，右圆点 = 下一页；**手指按下瞬间**就翻页并振动
  （`Haptics.tick`），颜色提亮 200ms。已在首/末页时按对应圆点无效果
  （不回绕）。

### 4.2 横滑翻页

- 热区 = 导航条本体长度（不横向扩展）× 纵向 52px。
- 方向锁定：横移超过 **8px** 且横移 > 纵移×1.1 → 判定横滑，转鼓与
  左下页名牌立即浮现，长按计时器取消。
- 慢拖可精调到任意页间位置（磁力曲线：靠近整页粘滞、中间易滑落）；
  松手时释放速度绝对值 >1.15 走惯性（可跨多页），否则就近吸附。
- 落位后转鼓与页名牌在屏上停留 **650ms** 后同速淡出；拖动中途改上甩
  会**立即**隐藏两者。页名牌文字在拖动跨过页中点时硬切，并播放一次
  赛博故障动画（切片闪烁/抖动/色差/白线）：唤醒当帧播一次，之后在
  转鼓收起前每成功翻过一页重播一次；在第一/最后一页继续滑的回弹不播。

### 4.3 双击直达

- 300ms 窗口内在导航条上点第二下：按**第二下的横向位置**直接跳到该页。
- 映射：把缩短后的导航条行程按页数等分（与拇指滑块同宽规则），
  第二下落在第几段就翻到第几页（已夹到首尾页范围内）。

### 4.4 上甩与快捷操作弧

- 锁定条件：上移超过 **16px** 且纵移 > 横移×2；超过 28px 死区后按主导方向
  兜底归类。
- 弧是一条按真机手指轨迹拟合的**四分之一椭圆**（半轴 横 116 × 纵 184），
  起点在「缩短导航条左起 1/4、垂直中点」处，先竖直上升、末端拐向水平。
- 当前 3 个操作（均为占位，触发弹 1 秒「『xx』功能开发中」SnackBar），
  **沿弧从下到上**依次为：

    | 顺序 | 操作 | w=360 参考坐标（圆心） |
    |---|---|---|
    | 下 | **应用**（apps） | ≈ (222, 708) |
    | 中 | **新建**（create） | ≈ (244, 640) |
    | 顶 | **语音**（voice） | ≈ (290, 585) |

  （原点 ≈ (218.5, 755)；即按钮相对原点分别上移约 48 / 115 / 170px，
  右移 4 / 26 / 71px。屏宽变化时整体按公式平移，见第 5 节。）
- 按钮直径 **40**；热区为圆形，半径 20~30（数量少时取 30，
  即按钮外扩 10px），弧上数量变化时热区自动重算（数量驱动，无硬编码 3）。
- 弧一弹出就选中离手指最近的热区内按钮（越过会 tick 振动并切换高亮）；
  **松手时手指仍在某热区内才触发**（confirm 振动 + 涟漪 + SnackBar），
  否则直接收起——这就是「快捷弧反悔」。

### 4.5 长按搜索

- 导航条上按住 **450ms** 且手指未移动 → confirm 振动，真实导航条在该帧
  交给独立的搜索胶囊（全宽、高 **44**、左右各留 14，底边距 16+sb）。
- **倒计时边框（fuse）**：展开后先有 0.65s 宽限（边框静止），随后蓝线在
  **2 秒内烧完**，烧完自动收起。点胶囊任意处让输入框聚焦进入输入态后，
  **倒计时取消**；失焦 150ms 内没有重新聚焦则自动收起。
- 空输入时上方列「历史胶囊」（细描边、无底色），点历史条目直接带入并搜索；
  输入时实时出结果行，点结果跳转对应页面、记入历史并收起；键盘提交只存历史。
- **点胶囊外任意处（全屏隐形 scrim）= 关闭**；系统返回键也关闭。

### 4.6 把手条：竖单与抽屉

**点按 → 本页操作竖单**（从把手位置向上生长的胶囊，340ms 生长、
按钮错峰弹入）。当前固定 3 个圆形按钮，**从上到下**：

| 顺序 | 操作 | 现状 |
|---|---|---|
| 上 | 刷新（refresh） | 占位 SnackBar |
| 中 | 分享（share） | 占位 SnackBar |
| 下 | 置顶（pin） | 占位 SnackBar |

按钮直径 = (把手宽−12) 夹在 32~42（w=360 时为 32），竖单总高约 127；
圆心 x = 把手中心（w=360 时 ≈ 35.6）。点按钮：confirm 振动、涟漪、
执行、竖单自动收起；点遮罩或返回键只收起。

**右拖 → 侧边抽屉**：

- 锁向：横移 >6px 且横移 > 纵移×1.1；上移 >16 占优进入竖直死区（无动作）；
  位移超 28px 后按主导方向兜底。
- 抽屉宽 = min(78vw, 340)（w=360 时 280.8），右圆角毛玻璃；把手跟手移到
  **停靠位** = 抽屉宽+14（w=360 时 ≈ 294.8）。
- 松手按进度 **0.5** 吸附开/合：开启动画 420ms、关闭动画 **100ms**（快收）。
- 抽屉当前是空壳（内容不接事件）；遮罩黑 α.44，点遮罩 / 返回键关闭。
- 抽屉已开时再**点按把手 = 关抽屉**（不是开竖单）。

### 4.7 AI 条与 AI 对话框

- 按住 450ms（期间移动距离 ≤8px）→ confirm 振动，对话框升起（320ms，
  高 min(52%屏高, 360)，圆角 22）并自动唤起键盘。
- 当前对话框**只能打字**：消息区为空、发送键恒禁用；点遮罩或返回键关闭。
- 按压时 AI 条整体增亮、光晕加强；移动超 8px 取消本次长按且无任何动作。

### 4.8 聊天页操作

- **会话行**高 72：48px 空心圆头像 + 昵称 + 预览，行间是屏宽 80% 居中的
  1px 分隔线；无会话时整屏居中显示 13px「暂无消息」。
- **未读绿点**：未读行右上 8px 绿色呼吸点；点进/点按该行即已读、绿点消失。
- **左滑操作区**：恒为两个按钮、每个宽 **76**（总露出宽 152）——
  左按钮切换读状态（未读行显示「已读」/已读行显示「未读」），
  右按钮红色「删除」。
  - 拖动全程跟手；松手时横向速度 >300px/s 按方向甩动判定，否则按
    **半程（76px）**吸附；吸附动画 180ms。
  - 全局同屏只展开一行；开始竖向滚动列表时展开行自动收回。
- **锚点已读规则**：在聊天页连续停留 **700ms** 不算自动已读——聊天锚点
  完全由会话未读数据驱动：所有会话都已读，锚点才恢复白色；左滑把任一行
  置为未读会重新点亮绿色呼吸。

### 4.9 导航锚点状态（导航条内的小竖条）

每页对应一根锚点，常态白色（tone2，被不透明滑块挡住，静止时看不见发光）：

- **通知**：绿色呼吸（如聊天有未读会话）。
- **异常**：红色急闪；仅翻到该页**不会**解除，必须显式处理。
  当前通过日志页的 debug「处理异常」按钮解除（真实业务接入后改由业务上报解除）。

## 5. 坐标与热区公式（测试/自动化用）

全部来自 `DockGeometry` + MediaQuery 静态推算；写测试坐标时**从公式算**，
不要散落魔数。

| 元素 | 左 x | 右 x | 顶 y | 底 y |
|---|---|---|---|---|
| 把手条 | 14 | 14 + 0.12w | h−sb−26 | h−sb−16 |
| AI 条 | 28+0.12w | 左 + (0.38w−56) | 同把手 | 同把手 |
| 导航整体 | w−14−w/2 | w−14 | 同把手 | 同把手 |
| 右圆点 | w−24 | w−14 | 同把手 | 同把手 |
| 左圆点 | w−14−w/2 | +10 | 同把手 | 同把手 |
| 导航条本体 | 左圆点右+5 | 右圆点左−5 | 同把手 | 同把手 |
| 搜索胶囊 | 14 | w−14 | h−sb−60 | h−sb−16 |

- 三条的**隐形纵向热区**统一：`顶−32 ~ 底+10`；横向：把手/AI/导航条
  = 自身宽度不扩展，圆点 = 直径 2 倍（20px 宽）。
- 快捷弧原点：`x = 导航条本体左 + 导航条宽/4`，
  `y = h−sb−16−5`；弧上点 =
  `(ox + 116(1−cos(πt/2)), oy − 184·sin(πt/2))`，
  多按钮按**弧长等距**在曲线中段窗口（3 个时为弧长 0.20/0.50/0.80）排布。
- 抽屉：宽 min(0.78w, 340)；把手停靠位 x = 抽屉宽 + 14。
- 竖单：按钮直径 `(0.12w−12).clamp(32,42)`；按钮圆心
  x = 14 + 0.06w；展开后底边与把手底齐、向上生长。

**w=360 参考值**：把手 14~57.2；AI 条 71.2~152；导航整体 166~346；
把手宽 43.2、竖单钮径 32、抽屉宽 280.8、停靠位 294.8。

> 系统开发者选项的「显示布局边界」对本 App **无效**（Flutter 自绘，
> 全局只有一个原生 View）。调试布局边界需用 Flutter 的
> `debugPaintSizeEnabled`（计划在终端页加内置开关）。

## 6. 浮层互斥与系统返回键

- 竖单 / AI 对话框 / 抽屉 / 搜索框 / 快捷弧**同屏至多一个**；唤起新会自动
  关掉其他浮层。浮层打开时其全屏遮罩拦截底部三条的所有其他手势。
- 系统返回键（v0.4.12 起）按固定顺序**每次只关一层**：
  **搜索 → 快捷弧 → 竖单 → AI 对话框 → 抽屉**；全都没有时才退出 App。

## 8. 测试 agent 注意

1. **先读完本文 + [glossary.md](glossary.md) 再动手**；组件称呼以 glossary 为准。
2. 所有底部手势的接收者是根 `Listener`（按位置命中），不是各个按钮组件——
   写 widget 测试时用全局坐标 `tester.tapAt(Offset(...))` /
   `startGesture(Offset(...))`，坐标从第 5 节公式按测试 surface 尺寸计算。
3. 手势判据都有死区/时长：长按类 450ms、AI 取消 8px、导航锁向 8px/16px、
   把手锁向 6px/16px、双击窗口 300ms、已读停留 700ms；测试时间用
   `tester.pump(...)` 手动推进帧时钟，**不要 pumpAndSettle**
   （AI 条/锚点有常驻循环动画）。
4. 占位功能（快捷弧 3 项、竖单 3 项、AI 对话框发送、抽屉内容）弹
   「开发中」SnackBar 是**预期行为**，不要报为 bug；真正要报的是
   「按了完全无反馈」。
5. 手感、热区、弧轨迹是否跟手以**真机**验收为准，模拟器与单元测试不能替代。
