# 解耦的 Flutter 组件与开合动画

用户明确偏好：组件之间尽量解耦、需要时留足接口、方便维护。涉及
多形态组件（如导航条 ↔ 搜索框）或开合动画时遵循本规范。

## 拆分原则

1. **一种形态一个组件**，不要让同一组件既承担静止态又承担变形态。
   会出现覆盖层层级错乱（下层元素画到上层之上）、收回时内部元素
   （滑块/锚点）穿帮。
2. 用一个**编排组件**（orchestrator）持有显隐状态位，同帧切换两个
   独立组件。参考案例（搜索胶囊，commit aea128c / v0.4.5）：
   - `_showNav`：真实导航条仅常规态挂载；搜索开始的同一帧隐藏；
   - `_keepPill`：变形组件关闭动画播完才卸载，避免半途消失；
   - `_opening`：方向位，决定过渡组件内部哪些装饰参与（收回时
     滑块/锚点恒不出现，只在最后由真实组件揭示）。
3. 变形组件的**起始帧必须与原组件外观完全一致**，替换才不可察觉；
   再由它独立过渡到目标形态。
4. **留接口而非写死**：跨组件数据通过构造参数/回调传入，编排组件
   不直接读子组件内部状态；可变状态（ChangeNotifier 等）由父级在
   build 时捕获为不可变字段向下传。

## 动画实现规范

1. `didUpdateWidget` 比较新旧状态时，不能读同一个可变 Notifier 的
   属性——新旧 widget 拿到的都是现值，永远相等。
2. 多个 AnimationController 的 State 必须 mixin
   `TickerProviderStateMixin`（SingleTicker 会断言）。
3. `Stack`/`Row` 中条件插入子节点时，常驻子节点必须带稳定 `Key`，
   否则后续同类型元素配对错位、RenderObject 被重建、首帧动画被跳过。
4. 帧外被调用的逻辑（如 openSearch）不要读帧时间戳；需要帧时钟时
   在展开后首个物理帧惰性记录。

## 流畅性（防止"低帧率慢速"观感）

逐帧动画期间消除重布局，尤其是 TextField/RenderParagraph：

1. **形状层无子女**：只放轻量 ColoredBox/DecoratedBox，每帧重布局
   成本极低。
2. **内容层固定尺寸**：把文本/复杂内容放在固定为目标尺寸的
   Positioned 层里只动 opacity；超出当前尺寸的部分由 ClipRRect
   裁掉。约束逐帧不变，布局命中缓存。
3. 整块动画外包 `RepaintBoundary`，重绘不向上污染页面轨道等层级。
4. **描边/阴影画在 ClipRRect 之外**：`Border` 的线跨盒缘（一半
   在内、一半在外），画在 ClipRRect 里外侧一半会被裁掉，整条边框
   变细。正确结构是「颜色+边框」合成一个 DecoratedBox 放在裁剪层
   之外，ClipRRect 只裁剪内容。
5. **圆角每帧显式 clamp 到 `min(宽/2, 高/2)`**：给 ClipRRect 传
   超大名义半径（如 999）时，渲染器会做**横纵独立夹取**（rx 夹
   宽/2、ry 夹高/2），动画中会得到"竖直长边+上下小弧"的椭圆角、
   两端像被矩形遮罩。由动画每帧算出当前外框宽并显式夹取，两端
   才能始终保持半圆。
6. 怀疑卡顿时用
   `adb shell dumpsys gfxinfo <pkg> reset` → 触发动画 →
   `dumpsys gfxinfo <pkg>` 检查 Janky frames / Missed Vsync；
   注意 screenrecord 本身有负载，是最差工况。

## 视觉一致性

- 交互反馈只在"有必要"时给：滑块按下**无任何外观变化**；
  端点圆点按下翻页时提亮到 tone2（白 α.42）。曾把两者统一为
  近黑按压色，用户先后否掉，已回退。无视觉变化的按压态也
  不要在 State 里保留对应字段。
- 重叠元素需要"融入"时用同一颜色（锚点默认色与滑块同为 tone2、
  锚点不发光）。
- 覆盖层底板必须不透明才能完全盖住下层（α.9 的底板会透出下层
  元素）；改本地颜色即可，不要为单一用途修改共享色板常量。
- 被前景遮挡的元素**优先用物理遮挡，不要写显隐逻辑**：把被遮
  元素常挂载、画在不透明前景的下层，让它自然地从前景边缘滑入
  滑出。按位置阈值显隐会在临界点（元素恰在边缘）突然弹出/消失，
  露馅。前提是前景必须真正不透明——半透明两层同色叠加会变亮，
  反而显形；可用与「旧半透明合成结果」等亮的**不透明灰**替代
  （本项目滑块 _thumbFill = 0xFF838383，即 tone1+tone2 合成白量
  0.513 的灰度；勿写成 0x83FFFFFF 半透明白，外观一样但挡不住）。
